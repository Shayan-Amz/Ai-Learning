# ابزار تولید نسخه توسعه‌یافته گزارش کارآموزی دماوند انرژی عسلویه

این پوشه شامل اسکریپت‌ها و متن فصل‌های افزوده‌شده به گزارش کارآموزی است. با اجرای `build.py`
نسخه توسعه‌یافته گزارش (فایل `گزارش-کارآموزی-دماوند-انرژی-عسلویه-ویرایش-توسعه‌یافته.docx` در
ریشه مخزن) از روی فایل اصلی ساخته می‌شود؛ قالب، سبک‌ها (Styles)، راست‌به‌چپ بودن متن‌ها،
شماره‌گذاری سرفصل‌ها و ساختار جداول عیناً مطابق فایل اصلی حفظ می‌شود.

## اجرا

```bash
python3 tools/report_builder/build.py
```

پیش‌نیاز: `python-docx` و `lxml`

```bash
pip install python-docx lxml
```

## ساختار فایل‌ها

| فایل | توضیح |
| --- | --- |
| `c1.py` | فصل دهم — چرایی وجود واحد تصفیه پساب |
| `c2.py` | فصل یازدهم — پرسنل، ساختار سازمانی و ارکان صنعتی |
| `c3.py` | فصل دوازدهم — کنترل فرآیندها، ابزار دقیق و پایش |
| `c4.py` | فصل سیزدهم — مواد مورد نیاز و مواد شیمیایی مصرفی |
| `c5.py` | فصل چهاردهم — شیوه اجرا، بهره‌برداری و عملکرد واحد |
| `c6.py` | فصل پانزدهم — مقاطع اقتصادی و تحلیل هزینه–فایده |
| `c7.py` | فصل شانزدهم — عملکرد مجموعه با تصفیه پساب + پیوست اختصارات + منابع تکمیلی |
| `pages.py` | مدل تخمین تعداد صفحات بر پایه چیدمان متن (کالیبره‌شده با سند اصلی) |
| `build.py` | ساخت فایل خروجی: درج فصل‌های جدید و شماره‌گذاری مجدد فصل جمع‌بندی به «فصل هفدهم» |

## نکته‌ها

- هر بلوک متنی در فایل‌های `c*.py` به شکل `("p", "متن")`, `("h3", "عنوان")`, `("tbl", [[...]])`
  و `("bullets", [...])` تعریف می‌شود؛ افزودن یا ویرایش محتوا با همین ساختار انجام می‌گیرد.
- اعداد فصل مقاطع اقتصادی «برآوردی/نمونه‌ای» هستند و باید با ارقام واقعی و روز شرکت به‌روزرسانی شوند.
- تخمین حجم افزوده‌شده (با `pages.py`) حدود ۲۲ صفحه معادل متن اضافه است.
