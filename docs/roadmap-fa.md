# نقشه‌راه پروژه و یادگیری Local Research Agent

## هدف ثابت پروژه

ساخت یک Agent پژوهشگر روی فایل‌های محلی که فقط سندهای انتخاب‌شده را می‌خواند و پاسخ را با ارجاع قابل‌بررسی به فایل و خط برمی‌گرداند. Pathfinder Canada یک prototype قدیمی و جداست؛ هدف فعلی نیست.

## وضعیت نسخه‌ی ۱

نسخه‌ی وب‌محور در `local_research_agent/` پیاده شده است:

- رابط FastAPI محلی، انتخاب/فهرست/حذف صریح سند، و workspace نادیده‌گرفته‌شده در Git.
- جست‌وجوی رتبه‌بندی‌شده برای Markdown/TXT، خواندن محدود و حفظ شماره‌ی خط.
- Agent loop با registry مجاز، جست‌وجو قبل از خواندن، citation validation و سقف step.
- حالت آفلاین extractive؛ planner مبتنی بر tool-calling به‌صورت اختیاری.
- consent پرسش‌به‌پرسش برای مدل راه‌دور، URL امن و نگه‌نداشتن chat history.
- تست‌های API/Agent/security، evaluation کوچک Hit@k و MRR، و CI.

جزئیات معماری در [Agent Architecture](agent-architecture-fa.md)، محدودیت‌های اعتماد در [Safety Review](safety-review-fa.md)، و معیارها در [Evaluation](evaluation-fa.md) هستند.

## ترتیب تکمیل و بازبینی

1. اجرای برنامه روی Windows و بررسی UX با چند فایل غیرحساس.
2. اجرای lint، تست، coverage و retrieval evaluation؛ رفع تمام regressions که در این repo بازتولید می‌شوند.
3. در صورت تمایل، اتصال و آزمون یک مدل tool-capable محلی؛ هیچ API key یا فایل حساس برای این مرحله لازم نیست.
4. گسترش ارزیابی با سؤال/منبع‌های دستی، و تصمیم‌گیری آگاهانه درباره‌ی PDF یا embedding فقط اگر نیاز واقعی باشد.
5. پس از آماده‌شدن برنامه، آموزش کد به درخواست کاربر و مرحله‌به‌مرحله شروع می‌شود؛ تا آن زمان هیچ toy lesson جدیدی اولویت ندارد.

## یادگیری در مرحله‌ی بعد

وقتی کاربر آماده باشد، مسیر آموزش روی همین محصول می‌ماند و به‌ترتیب انجام می‌شود: مدل ذهنی Agent، loop و قراردادها، ابزارهای محدود، retrieval و citation، planner مدل‌محور، تست/ارزیابی و مرزهای ایمنی. در آموزش، هر خط کدی که ارائه می‌شود با کارکرد، دلیل و معنای خروجی توضیح داده می‌شود؛ تمرین از خود پروژه خواهد بود، نه مثال toy نامرتبط.

درس‌های ۰ تا ۱۵ در `docs/lesson-00...lesson-15...` یادداشت‌های مقدماتی قدیمی‌اند و برای کامل‌کردن پروژه‌ی فعلی لازم نیستند. درس‌های ۱۶ تا ۱۸ به نسخه‌ی جدید به‌روزرسانی شده‌اند.
