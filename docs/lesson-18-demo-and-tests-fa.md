## فرمان تست و معنای نتیجه

```powershell
python -m pytest -q
```

`python -m pytest` تست‌ها را با همان Python محیط فعال اجرا می‌کند؛ `-q` خروجی را خلاصه می‌کند. خروجی `6 passed` یعنی شش رفتار فعلی موفق‌اند، اما **به‌تنهایی کیفیت پاسخ یک LLM آینده را تضمین نمی‌کند**.

## مرور این درس

- demo همه‌ی اجزا را به هم وصل می‌کند و trace کوتاه نشان می‌دهد کدام ابزارها اجرا شدند.
- تست end-to-end مسیر واقعی را می‌سنجد؛ تست‌های جداگانه‌ی امنیت، allowlist و stop limit از regression جلوگیری می‌کنند.
- `tmp_path` داده‌ی موقت می‌سازد تا تست به فایل‌های شخصی یا اینترنت دسترسی نداشته باشد.
- گام بعدی ساخت `LLMPlanner` و تست خروجی tool-call مدل است؛ اجازه‌ی مدل به همان دو ابزار محدود می‌ماند.
- سؤال مرور: اگر planner همیشه `ToolCall` برگرداند، کدام تست باید جلوی ادامه‌ی نامحدود را بگیرد؟
